# 🏠 Data Entry Job Bot

This project was completed as part of **Day 53** of the
**100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

## 📌 Project Overview

This project uses Selenium WebDriver and Beautiful Soup to automate a data entry task. It scrapes property listings from a website and enters the collected information into a Google Sheet.

---

## 🧠 Concepts Practiced

* Web Scraping
* Beautiful Soup
* Selenium WebDriver
* Browser Automation
* Google Forms Automation
* Data Extraction

---

## 🚀 Technologies Used

* Python
* Selenium
* Beautiful Soup
* Requests

---

## 💡 What I Learned

Through this project, I learned how to combine web scraping with browser automation to collect data from one website and automatically enter it into another.
