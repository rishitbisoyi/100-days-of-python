This project was completed as part of **Day 60** of the

- HTML Forms
- Flask POST Requests
- Form Data
- Sending Emails with `smtplib`

## 🚀 Technologies Used

- Python
- Flask
- HTML
- SMTP

## 💡 What I Learned

I learned how to create HTML forms, handle submitted data with Flask, and use `smtplib` to send emails.
