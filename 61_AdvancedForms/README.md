# 📝 Advanced Forms with Flask-WTF

This project was completed as part of **Day 61** of the

## 📌 Project Overview

- WTForms
- Form Validation
- Receiving Form Data
- Jinja2 Template Inheritance
- Bootstrap-Flask

## 🚀 Technologies Used

- Python
- Flask
- Flask-WTF
- WTForms
- Jinja2
- Bootstrap

## 💡 What I Learned

I learned how to create structured and validated forms with Flask-WTF and use template inheritance and Bootstrap to improve their design.
