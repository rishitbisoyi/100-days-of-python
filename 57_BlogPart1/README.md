# 📝 Blog Website – Part 1

This project was completed as part of **Day 57** of the  
**100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

## 📌 Project Overview

This day focused on using **Jinja templating with Flask** to create dynamic HTML pages. The first part of the Blog Capstone Project applies these concepts to build the foundation of a blog website.

## 🧠 Concepts Practiced

- Jinja Templating
- Dynamic HTML
- Flask Routing
- URL Building
- Using APIs with Flask

## 🚀 Technologies Used

- Python
- Flask
- Jinja
- HTML
- CSS

## 💡 What I Learned

I learned how to use Jinja to generate dynamic content and connect Flask routes with HTML templates.
