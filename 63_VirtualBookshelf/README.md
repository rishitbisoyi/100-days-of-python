# 📚 Virtual Bookshelf

This project was completed as part of **Day 63** of the  
**100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

## 📌 Project Overview

A Flask web application for managing a personal bookshelf. Books can be added, updated, and deleted using a SQLite database.

## 🧠 Concepts Practiced

- Flask
- SQLite
- SQLAlchemy
- CRUD Operations
- HTML Forms
- Jinja Templates

## 🚀 Technologies Used

- Python
- Flask
- SQLAlchemy
- SQLite
- HTML
- CSS

## 💡 What I Learned

I learned how to connect a Flask application to a SQLite database using SQLAlchemy and perform CRUD operations.
