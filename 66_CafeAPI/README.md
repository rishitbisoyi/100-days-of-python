# 🌐 RESTful API

This project was completed as part of **Day 66** of the  
**100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

## 📌 Project Overview

This project involved building a RESTful API for managing cafe data. The API supports retrieving, adding, updating, and deleting cafes using different HTTP methods.

## 🧠 Concepts Practiced

- REST APIs
- HTTP Methods
- GET, POST, PUT, PATCH & DELETE
- RESTful Routing
- Postman
- API Documentation

## 🚀 Technologies Used

- Python
- Flask
- REST API
- Postman

## 💡 What I Learned

I learned how REST APIs work and how to build API endpoints that allow applications to interact with and modify data using different HTTP methods.
