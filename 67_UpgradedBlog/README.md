# 📝 RESTful Blog

This project was completed as part of **Day 67** of the  
**100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

## 📌 Project Overview

This project continued the Blog Capstone Project by adding RESTful routing and allowing blog posts to be viewed, created, edited, and deleted through API requests.

## 🧠 Concepts Practiced

- RESTful Routing
- GET & POST Requests
- PUT & DELETE Requests
- Flask
- APIs
- CRUD Operations

## 🚀 Technologies Used

- Python
- Flask
- REST API
- HTML
- Jinja

## 💡 What I Learned

I learned how to use RESTful routes to perform CRUD operations on blog posts and connect API endpoints with a Flask application.
