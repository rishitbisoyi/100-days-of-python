# ☕ Coffee & WiFi

This project was completed as part of **Day 62** of the  
**100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

## 📌 Project Overview

A Flask website that displays cafes based on their coffee, WiFi, and seating availability. It also includes a form for adding new cafes to the list.

## 🧠 Concepts Practiced

- Flask
- Flask-WTF
- HTML Forms
- CSV File Handling
- Bootstrap
- Jinja Templates

## 🚀 Technologies Used

- Python
- Flask
- Flask-WTF
- HTML
- Bootstrap
- CSV

## 💡 What I Learned

I learned how to build a Flask website with forms and store and retrieve data using a CSV file.
