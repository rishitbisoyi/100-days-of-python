## 🧠 Topics Covered

- Web Design Fundamentals
- Color Theory
- Typography
- User Interface (UI) Design
- User Experience (UX) Design

I learned the basic principles behind effective web design, including how colors, typography, layout, UI, and UX influence how users perceive and interact with a website.
