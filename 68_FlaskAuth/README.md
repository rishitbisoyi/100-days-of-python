# 🔐 Authentication with Flask

This project was completed as part of **Day 68** of the  
**100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

## 📌 Project Overview

This project focused on adding user authentication to a Flask application, including user registration, login, password hashing, and secure password storage.

## 🧠 Concepts Practiced

- User Authentication
- User Registration & Login
- Password Hashing
- Salting
- Werkzeug Security
- Flask Sessions

## 🚀 Technologies Used

- Python
- Flask
- Werkzeug
- HTML
- Jinja

## 💡 What I Learned

I learned how authentication works in web applications and how passwords can be securely stored using hashing and salting instead of storing them as plain text.
