# 👥 Blog Capstone – Adding Users

This project was completed as part of **Day 69** of the  
**100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

## 📌 Project Overview

This part of the Blog Capstone Project adds **user authentication and user-specific features** to the blog. Users can register, log in, access protected routes, and add comments to blog posts.

## 🧠 Concepts Practiced

- User Registration & Login
- Authentication
- Protected Routes
- Relational Databases
- User Sessions
- Adding Comments

## 🚀 Technologies Used

- Python
- Flask
- Flask-WTF
- SQLAlchemy
- SQLite
- Jinja
- Werkzeug

## 💡 What I Learned

I learned how to connect users with database records, protect routes that require authentication, and allow logged-in users to interact with blog posts.
