# 🎬 My Top 10 Movies

This project was completed as part of **Day 64** of the  
**100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

## 📌 Project Overview

A Flask web application for managing a personal list of favourite movies. Movies can be added, edited, deleted, and sorted by rating.

## 🧠 Concepts Practiced

- Flask
- SQLite
- SQLAlchemy
- CRUD Operations
- Jinja Templates
- HTML Forms
- Sorting and Ranking Data

## 🚀 Technologies Used

- Python
- Flask
- SQLAlchemy
- SQLite
- HTML
- CSS

## 💡 What I Learned

I learned how to build a database-driven Flask application with full CRUD functionality and dynamically display and rank stored data.
