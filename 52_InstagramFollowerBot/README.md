# 📸 Instagram Follower Bot

This project was completed as part of **Day 52** of the
**100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

## 📌 Project Overview

This project uses Selenium WebDriver to automate Instagram interactions. The bot logs into Instagram, searches for a target account, and automatically follows the followers of that account.

* Selenium WebDriver
* Browser Automation
* Automated Login
* Finding and Clicking Web Elements
* Handling Dynamic Web Pages

## 🚀 Technologies Used
