# 📊 Data Science with Pandas

This project was completed as part of **Day 72** of the  
**100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

## 📌 Project Overview

This project focused on exploring and analysing a dataset of college majors and their earning potential using **Pandas**.

The analysis involved examining salary data, comparing different degrees, identifying the highest and lowest earning majors, and analysing risk and potential using the available data.

## 🧠 Concepts Practiced

- Pandas
- DataFrames
- Data Cleaning
- Data Exploration
- Accessing Columns and Rows
- Sorting Data
- Adding Columns
- Grouping & Pivoting Data

## 🚀 Technologies Used

- Python
- Pandas
- Jupyter Notebook
- CSV

## 💡 What I Learned

I learned how to use Pandas to load, clean, explore, manipulate, and analyse data stored in CSV files.
