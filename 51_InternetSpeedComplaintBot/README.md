# 🌐 Internet Speed Complaint Automation

This project was completed as part of **Day 51** of the
**100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

## 📌 Project Overview

This project uses Selenium WebDriver to automatically check internet speed and, if the connection is slower than the promised speed, log in to X and post a complaint to the internet service provider.

---

## 🧠 Concepts Practiced

* Selenium WebDriver
* Browser Automation
* Web Element Interaction
* Automated Login
* Posting on Social Media

---

## 🚀 Technologies Used

* Python
* Selenium WebDriver

---

## 💡 What I Learned

Through this project, I learned how Selenium can be used to automate interactions across different websites and perform a complete workflow based on collected data.
