# 🎯 Higher Lower Game

This project was completed as part of **Day 55** of the  
**100 Days of Code: The Complete Python Pro Bootcamp** by Angela Yu.

## 📌 Project Overview

A simple Flask web game where the user tries to guess a randomly generated number between **0 and 9** by entering their guess directly into the URL.

For example: `/5`

The application then checks the guess and displays whether it is correct, too high, or too low.
